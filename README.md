Vulkan renderer. 

## Getting Started

### Requirements
+ C++20 compiler
+ CMake 3.16+
+ Vulkan SDK 1.3+

### Building
1. Clone this repository recursively.
2. Configure with CMake.
3. Run the generated Makefile.


*NOTE: Only tested on Linux using Clang 19.1.7*
